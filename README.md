Sales Performance Dashboard (Power BI)

Porject Overview 
This project focuses on applying sales data and building an interactive Power BI dashboard to uncover key business insights. The dashboard provides a clear view of regional performance and category-wise sales distribution.

Tools Used 
- Power BI
- SQL
- Excel

Dataset
The dataset contains sales transaction records with the following fields:
- Order ID
- Region
- Category
- Sales

Dashboard Preview 
Key Insights
- The West Region generated the highest sales among all regions.
- The South region showed the lowest sales peformmance.
- Technology category contributed the highest share of total sales.
- Sales distribution across categories is relatively balanced.

Conclusion
This dashboard helps in undersgtanding business performance and supports better decision-making usind data visualization.
